# Painted assets

Everything here was cut from the two reference paintings the site's look is based on
(a floating-island palace with waterfalls, orchards and drifting lantern-hung drapes).
They are used as real art by `web/sanctuary/art.js`; if one fails to load, a procedural
drawing stands in.

| File | What it is | Used for |
|---|---|---|
| `plate_sky.jpg` | The painted sky, far palace, floating islands and mountains (drapes painted out) | The distant backdrop, slid slowly for parallax |
| `valley.jpg` | The green river valley under the cliff | The land far below the island |
| `palm_grove.png`, `tree_pomegranate_a.png`, `tree_pomegranate_b.png` | Date palms with fruit; pomegranate trees | Island margins, the garden court, the far ridge |
| `rock.jpg` | Dark stratified cliff face | The island's rock body (tiled, mirrored) |
| `river.jpg`, `waterfall.jpg` | Painted river and falling water | The river under the glass floor (scrolling) and the waterfall |
| `carve.jpg`, `frieze.jpg`, `panel.jpg`, `mosaic.jpg` | Carved sandstone, tile frieze, relief panel, courtyard mosaic | Columns, floor fronts, wall panels |
| `grass.jpg` | Painted meadow | The far hills the armies march on |
| `curtain_l.png`, `curtain_r.png` | The ornate drapes with hanging lanterns | Framing the corners of the screen |
