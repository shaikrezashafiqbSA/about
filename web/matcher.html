How to enable Chrome's built-in AI (Gemini Nano)
  1. Use Chrome 127+ (Canary/Dev/Beta recommended — the feature is newest there).
  2. Go to chrome://flags/#optimization-guide-on-device-model and set it to Enabled BypassPerfRequirement.
  3. Go to chrome://flags/#prompt-api-for-gemini-nano and set it to Enabled.
  4. Relaunch Chrome.
  5. Go to chrome://components, find Optimization Guide On Device Model, and click Check for update to force it to download (it's a few GB — this can take a while).
  6. Reload this page and pick "Chrome Built-in AI" above. If it still says unavailable, wait for the component download to finish and reload again.

WebLLM vs Chrome Built-in AI: WebLLM runs a model you choose (e.g. Llama 3) entirely in-page via WebGPU — portable across browsers but has to download several GB on first use and is generally slower per-token. Chrome's built-in AI uses Gemini Nano, a model Chrome itself manages and shares across all sites/extensions — no per-site download, lower latency, and less memory pressure, but it's Chrome-only, the model is smaller/less capable than Llama-3-8B, and today it's still gated behind experimental flags. In practice the biggest difference for this tool is context window size: Gemini Nano's input limit is much smaller, so pasting a full resume plus a job description can trip a QuotaExceededError ("input is too large") — if that happens, switch to WebLLM.
